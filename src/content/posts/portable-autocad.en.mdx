**Short answer:** there's no official portable AutoCAD. Autodesk only ships AutoCAD as an installed, signed-in program, and every "AutoCAD portable" download is a cracked copy. If you need CAD that runs from a USB stick or without installing:

- **Windows:** CADCraft's portable ZIP (x64, x86 and arm64). Unzip and run `cadcraft.exe`.
- **Linux:** AppImages (CADCraft, FreeCAD, KiCad and others) or a plain `.tar.gz`.
- **A locked-down PC:** CAD in the browser, such as [CADCraft online](/online), or AutoCAD Web if you have a subscription.

_cadcraft.org is an independent guide, not affiliated with Autodesk. CADCraft is the ArtCraft team's open-source CAD program ([getartcraft.com/apps/cadcraft](https://getartcraft.com/apps/cadcraft)). File names and sizes are from the CADCraft 0.14.0 release (28 October 2026)._

## Why there's no portable AutoCAD

AutoCAD is a large installed application. It writes to the Windows registry, installs shared runtimes and drivers, and checks a named-user licence when you sign in. None of that is designed to travel on a USB stick, and Autodesk has never released a portable edition.

"Portable AutoCAD", "AutoCAD portable installer" and similar downloads are repackaged copies with the licensing removed. Avoid them:

- **They're unlicensed.** Using one for paid work is software piracy, and companies get audited for it.
- **They're a classic malware carrier.** A modified installer that asks you to switch off your antivirus is exactly how password stealers and miners spread.
- **They break IT policy** on work and school computers, which is usually why people want a portable version in the first place.

The legal routes to real AutoCAD without a local install are AutoCAD Web (in the browser, part of an AutoCAD subscription) and the free [education licence](https://www.autodesk.com/education) for students and teachers. If you just need to **look at** a DWG, a viewer is enough; see [how to open a DWG file](/blog/how-to-open-dwg-file).

### Check the download

The release includes `SHA256SUMS.txt`. In PowerShell:

```powershell
Get-FileHash .\cadcraft-0.14.0-windows-x64-portable.zip
```

Compare the hash with the line for that file. Only download from `github.com/storytold/cadcraft`; check the owner is `storytold`.

## Make it truly portable: keep the settings on the stick

By default CADCraft saves its settings, recent-file list and logs to `%APPDATA%\CADCraft` on whichever computer it runs on. To keep them on the USB drive, point the `CADCRAFT_CONFIG_DIR` environment variable at a folder next to the program. A two-line launcher does it:

```bat
@echo off
set "CADCRAFT_CONFIG_DIR=%~dp0config" & start "" "%~dp0cadcraft.exe" %*
```

Save it as `CADCraft.bat` in the same folder as `cadcraft.exe` and start CADCraft from it. `%~dp0` is the folder the batch file is in, so it works whatever drive letter the stick gets.

![A portable CADCraft folder on a USB drive: cadcraft.exe and cadcraft-cli.exe from the portable ZIP, licence files, a CADCraft.bat launcher you add that sets CADCRAFT_CONFIG_DIR to a config folder next to it, and a drawings folder](/imgs/blog/portable-cad-usb-folder.svg)

Two useful variations:

- **Leave nothing behind at all.** If `CADCRAFT_CONFIG_DIR` is set but empty, CADCraft uses no settings folder: it starts with defaults and doesn't write settings anywhere.
- **Fonts.** CADCraft uses the TrueType fonts installed on the computer it runs on. Text styles that name a font the host PC doesn't have fall back to another font, so drawings with special fonts can look different from machine to machine.

## Linux: AppImage and tarballs

AppImages are portable by design: one file, mark it executable, run it. CADCraft ships `cadcraft-<ver>-linux-x86_64.AppImage` and an aarch64 build, plus `.tar.gz` archives you can unpack anywhere. FreeCAD and KiCad also publish AppImages, so a Linux stick can carry 2D, 3D and PCB tools together.

```bash
chmod +x cadcraft-0.14.0-linux-x86_64.AppImage
./cadcraft-0.14.0-linux-x86_64.AppImage
```

On macOS there's no real "portable" concept; the CADCraft app in its `.dmg` is a self-contained bundle you can copy anywhere, including an external drive.

## When even a portable app is blocked: CAD in the browser

Many school and office PCs block any `.exe` that isn't on an approved list, portable or not. Then the browser is the way in:

- **[CADCraft online](/online)** is the same program compiled to WebAssembly. No install, no account, and the drawing stays on your computer. It reads and writes DXF only (no DWG) and has no autosave, so save often.
- **AutoCAD Web** if you or your employer pay for AutoCAD.
- More options, including 3D tools, in [free online CAD software](/blog/free-online-cad-software).

You can even carry the browser version on the stick: the release's `cadcraft-web-0.14.0.zip` (10.3 MB) is a static site you can serve from any folder with a local web server.

## Portable CAD checklist

- **Download from the project's own release page,** never a "portable" repack.
- **Verify the SHA-256** against the published checksums.
- **Keep settings and drawings on the stick** (the launcher above).
- **Use a fast USB 3 drive.** Opening a 70 MB program from a cheap stick is noticeably slower.
- **Save DXF if you'll open the drawing elsewhere.** Every CAD program reads it.
- **Eject properly** before pulling the stick out, or the last save may not be written.
