## Verify the archive and start the CLI

1. Compare the download's SHA-256 hash with the matching filename in the release's checksum list. Use `shasum -a 256` on macOS, `sha256sum` on Linux, or `Get-FileHash -Algorithm SHA256` in PowerShell, followed by the archive path.
2. Extract the archive. Open a terminal in the folder that contains the binary. Run `./cadcraft-cli --version` on macOS or Linux, or `.\cadcraft-cli.exe --version` in PowerShell.
3. The examples below assume `cadcraft-cli` is on your PATH. Otherwise, use the same relative path to the executable or call it by its full path from your working folder.

## Run a complete example

Run these in an empty, writable folder. They generate the built-in bracket, inspect its entity counts and export a PDF preview. You can also [download the sample DXF](/examples/review-0180/bracket.dxf).

<CodeBlock
  code={[
    'cadcraft-cli sample bracket bracket.dxf',
    'cadcraft-cli info bracket.dxf',
    'cadcraft-cli convert bracket.dxf bracket.pdf',
  ].join('\n')}
/>

The v0.18.0 sample reports **46 entities**. The PDF command plots model space to a single page fitted to the drawing extents. Check the result in a PDF viewer before sending it on.

## Common commands

| Task                                             | Command                                                 |
| ------------------------------------------------ | ------------------------------------------------------- |
| Inspect a DWG without opening the desktop editor | `cadcraft-cli info drawing.dwg`                         |
| Write a new DXF from a DWG                       | `cadcraft-cli convert drawing.dwg drawing-copy.dxf`     |
| Export an SVG preview                            | `cadcraft-cli convert drawing.dxf drawing.svg`          |
| Compare after saving and reopening               | `cadcraft-cli roundtrip drawing.dwg --out check-report` |
| See conversion options                           | `cadcraft-cli convert --help`                           |

Use a new output filename and keep the source drawing. Read the round-trip report before treating a successful conversion as proof that the file was preserved. [See the DWG, DXF and PDF results from our benchmark](/blog/cadcraft-review).
