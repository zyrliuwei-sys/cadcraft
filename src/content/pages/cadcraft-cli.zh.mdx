## 校验并运行

1. 在 macOS 用 `shasum -a 256`，在 Linux 用 `sha256sum`，在 PowerShell 用 `Get-FileHash -Algorithm SHA256`，后接下载文件的路径，与发布页上同名文件的校验值核对。
2. 解压后，在可执行文件所在目录打开终端。macOS 或 Linux 运行 `./cadcraft-cli --version`，PowerShell 运行 `.\cadcraft-cli.exe --version`。
3. 以下示例假设已将命令加入 PATH。也可以从工作目录直接用可执行文件的完整路径。

<CodeBlock code="cadcraft-cli --version" />

## 跑一个完整示例

在空的可写目录运行以下命令，生成支架样例、检查图元数量并导出 PDF。也可[直接下载示例 DXF](/examples/review-0180/bracket.dxf)。

<CodeBlock
  code={[
    'cadcraft-cli sample bracket bracket.dxf',
    'cadcraft-cli info bracket.dxf',
    'cadcraft-cli convert bracket.dxf bracket.pdf',
  ].join('\n')}
/>

v0.18.0 的样例包含 **46 个图元**。PDF 命令将模型空间适配到单页。发送前，先用阅读器检查出图效果。

## 常用命令

| 任务                     | 命令                                                    |
| ------------------------ | ------------------------------------------------------- |
| 检查 DWG 内容            | `cadcraft-cli info drawing.dwg`                         |
| 把 DWG 另存为 DXF        | `cadcraft-cli convert drawing.dwg drawing-copy.dxf`     |
| 导出 SVG 预览            | `cadcraft-cli convert drawing.dxf drawing.svg`          |
| 对比保存并重打开后的差异 | `cadcraft-cli roundtrip drawing.dwg --out check-report` |
| 查看转换参数             | `cadcraft-cli convert --help`                           |

请保留原件并使用新文件名。即使转换成功，也要查看比较报告。[查看 DWG、DXF 和 PDF 实测](/blog/cadcraft-review)。
