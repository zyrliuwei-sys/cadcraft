## 判断与后续观察

1. 流量下降和转化下降同时发生，优先核对 Google 的入口、查询词和首页下载转化，再判断具体改动的影响。

3. 已有少量付费，当前更大的缺口仍是从免费使用走到 Pro。应观察保存、升级入口、套餐与支付之间的用户路径；每周一个付费样本不足以判断转化改善。

## 统计口径

- 按 `src/modules/analytics/service.ts` 的规则，在各查询时间范围内排除有内部标记的访客；与其关联的内部用户也排除。
- 每个事件独立按浏览器访客 ID 去重，跨设备不保证是同一个自然人。
- 注册读取用户表并通过事件关联到账户的最早访客；同一访客多个新增账户在注册访客数中只算一次。
- 支付读取状态为 `paid`、支付时间在范围内的订单；金额与看板一致，按订单 `amount / 100` 汇总，本次成功订单均为 USD。
- 周 UV 在一周内去重；日 UV 按各日独立计算，日 UV 相加不会等于周 UV。看板周报的 daily 分配方式不同，本报告日表使用各日独立窗口。
- 页面路径合并中英文版本；来源和首次入口来自浏览器保存的首次触达信息。
